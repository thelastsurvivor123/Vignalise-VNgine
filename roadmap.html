VIGNALISE VNGINE · DEVELOPMENT ROADMAP

A Very Awful Roadmap.

VVN is an evolving passion project. Progress will be slow.

Already in the engine

  • Write stories in regular HTML, with scenes, dialogue, narration, and branching choices.
  • Preview and follow a story while editing it.
  • Organize multiple HTML files and image assets in a project.
  • Link branches between HTML files and play a complete project from a ZIP archive.
  • Save projects in the current browser and import or export project ZIPs.
  • Play a story in a standalone reader.

Plans for the future

  • (Maybe) make story validation and preview errors clearer and easier to act on.
  • Add more (fandom-specific) assets.
  • Implement proper sprite functionality.
  • Implement the ability to customise the VN UI through HTML and/or CSS.
  • Continue refining the editor and reader experience on smaller screens.

These are areas being considered, not scheduled promises. There are no release dates yet; priorities may change as the engine develops.
